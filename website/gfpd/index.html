.gfpd plugin descriptors

A .gfpd file is a YAML text file that describes a GrooveForge plugin: its parameters, what it does, and the controls on its panel. Every bundled effect and MIDI FX has one.

What a file of your own can do today

typeStatus
midi_fxWorks. The app runs your chain of MIDI nodes on the notes that reach the module.
effectPanel only. The sound of the bundled effects is processed by built-in code chosen by the plugin's id. A file with a new id loads and shows its panel, but its graph is not run, so it does not process the sound.
instrument, analyzerSame as effect. The only bundled instrument, Riff, is built-in code.

Load a file

  1. Tap +, then Load .gfpd from file….
  2. Pick your file.

The plugin is added to the rack as a new module, and to the + menu.

  • The plugin stays in the + menu after a restart. The cross next to it removes it from the menu.
  • To try an edit, load the file again. The modules already in the rack switch to the new version and keep their knob positions.
  • A project saves a copy of the plugins it uses, so it plays on a device that never had the file.
  • Your id must not start with com.grooveforge.: those ids belong to the modules that come with the app, and the app refuses the file.
  • If the file is not a valid plugin, the app says so and adds nothing.

Example: a MIDI transposer

This is the bundled transposer.gfpd, without its comments.

spec: "1.0"
id: "com.grooveforge.transposer"
name: "Transposer"
version: "1.0.0"
type: midi_fx

parameters:
  - id: semitones
    paramId: 0
    name: "Semitones"
    min: -24
    max: 24
    default: 0
    unit: "st"

midi_nodes:
  - id: tr
    type: transpose
    params:
      semitones: { param: semitones }

ui:
  layout: grid
  groups:
    - label: "Pitch Shift"
      controls:
        - type: knob
          param: semitones
          label: "Semitones"

For your own plugin, change id first, to something like com.yourname.transposer: the app refuses ids that start with com.grooveforge. (see Load a file).

Top-level fields

FieldWhat it does
idUnique name in reverse-domain form, like com.yourname.myfx. Projects refer to the plugin by it, so never change it once people use your file.
nameName shown in the rack.
versionYour version number, as text.
typemidi_fx (or midifx), effect, instrument or analyzer. Missing or unknown means effect.
parametersThe settings the user can change. See Parameters.
midi_nodesFor midi_fx: the processing chain. See MIDI nodes.
graphFor effect: the audio graph. See Audio graph.
uiThe panel. See Panel.

The bundled files start with spec: "1.0". The app reads it but does not check it.

Parameters

A list under parameters:, one entry per setting.

FieldIf missingWhat it does
id(required)Text key. Nodes and controls refer to it, and projects save the value under it.
paramId0Number, unique within the file. Never reuse or renumber one once the file is in use.
nameEmptyLabel under the control.
min, max0Range shown on the panel.
default0Starting value, between min and max.
unitEmptyText after the value, like ms or %.
typefloatfloat (continuous), toggle (off/on) or selector (one of options).
optionsNoneFor a selector: the labels, in order. Set min: 0 and max to the number of options minus one.
displayNo readoutPrints the value under the control: integer (rounded), value (rounded, with the unit) or interval (semitones with the interval name).

Nodes do not see min and max. They receive the control's position from 0 to 1 and apply their own range: transpose always maps 0 to 1 onto −24 to +24 semitones. When you reuse a node, copy the range from the bundled file that uses it, or the panel will show one value while the node plays another.

MIDI nodes

A list under midi_nodes:. Notes go through the nodes in the order of the list. Each node has an id, a type and params. A node parameter is either linked to a plugin parameter, { param: semitones }, or fixed, { value: 0.5 }. A fixed value is on the same 0-to-1 scale.

Node typeNode parametersBundled example
transposesemitonestransposer.gfpd
gateminVelocity, maxVelocity, minPitch, maxPitchgate.gfpd
harmonizevoiceCount, interval1 to interval4, snapToScaleharmonizer.gfpd
chord_expandchordType, spread, snapToScalechord_expand.gfpd
arpeggiatepattern, division, gate, octavesarpeggiator.gfpd
velocity_curvemode, amountvelocity_curve.gfpd
microtonechordWindow, clusterMode, bendRange, velocityModemicrotone.gfpd

One unknown node type disables the whole chain.

Audio graph

Bundled effects describe their processing under graph:, with nodes and connections. As said above, the app does not run this graph today. For reference, the syntax is: 

graph:
  nodes:
    - id: in
      type: audio_in
    - id: rev
      type: freeverb
      params:
        roomSize: { param: room_size }
    - id: mix_nd
      type: wet_dry
      params:
        mix: { param: mix }
    - id: out
      type: audio_out
  connections:
    - from: in.out
      to: [rev.in, mix_nd.dry]
    - from: rev.out
      to: mix_nd.wet
    - from: mix_nd.out
      to: out.in

audio_in and audio_out are the plugin's input and output. The other node types are gain, wet_dry, freeverb, biquad_filter, delay, wah_filter, compressor and chorus. A connection goes from node.port to one target or a list. Without a port, from means out and to means in.

Panel

Under ui:, either a flat controls: list or a list of groups:. When both are there, the groups win.

FieldWhat it does
layoutWithout groups: row (the default, one line that scrolls) or grid (wraps onto several lines). With groups: lanes stacks each group on its own line; anything else places the groups to fit the screen.
groupsEach group has a label and its own controls list.
activeWhenOn a group, with layout: lanes only: { param: voice_count, atLeast: 2 } greys the group out while that parameter is below 2. The value is compared in the parameter's own units.

Each control has a type, and most have a param (a parameter id). label replaces the parameter's name, and size is small, medium (the default) or large.

Control typeShows
knobA rotary knob. Also used for a missing or unknown type.
sliderA slider.
toggleAn on/off button.
selectorA choice between the parameter's options.
intervalA bar for picking an interval in semitones.
vumeterA level meter. No param.
buttonWith action: reset, puts every parameter back to its default. No param.
