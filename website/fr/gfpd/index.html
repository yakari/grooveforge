Descripteurs de plugin .gfpd

Un fichier .gfpd est un fichier texte YAML qui décrit un plugin GrooveForge : ses paramètres, ce qu'il fait, et les commandes de son panneau. Chaque effet et chaque MIDI FX fourni en a un.

Ce qu'un fichier à vous peut faire aujourd'hui

typeÉtat
midi_fxFonctionne. L'application fait passer les notes qui arrivent au module dans votre chaîne de nœuds MIDI.
effectPanneau seulement. Le son des effets fournis est traité par du code intégré, choisi d'après l'id du plugin. Un fichier avec un nouvel id se charge et affiche son panneau, mais son graph n'est pas exécuté : il ne traite pas le son.
instrument, analyzerComme effect. Le seul instrument fourni, Riff, est du code intégré.

Charger un fichier

  1. Touchez +, puis Charger un fichier .gfpd….
  2. Choisissez votre fichier.

Le plugin est ajouté au rack comme nouveau module, et au menu +.

  • Le plugin reste dans le menu + après un redémarrage. La croix à côté de lui le retire du menu.
  • Pour tester une modification, rechargez le fichier. Les modules déjà dans le rack passent à la nouvelle version et gardent la position de leurs boutons.
  • Un projet enregistre une copie des plugins qu'il utilise : il joue aussi sur un appareil qui n'a jamais eu le fichier.
  • Votre id ne doit pas commencer par com.grooveforge. : ces id appartiennent aux modules fournis avec l'application, qui refuse le fichier.
  • Si le fichier n'est pas un plugin valide, l'application le signale et n'ajoute rien.

Exemple : un transpositeur MIDI

Voici le transposer.gfpd fourni, sans ses commentaires.

spec: "1.0"
id: "com.grooveforge.transposer"
name: "Transposer"
version: "1.0.0"
type: midi_fx

parameters:
  - id: semitones
    paramId: 0
    name: "Semitones"
    min: -24
    max: 24
    default: 0
    unit: "st"

midi_nodes:
  - id: tr
    type: transpose
    params:
      semitones: { param: semitones }

ui:
  layout: grid
  groups:
    - label: "Pitch Shift"
      controls:
        - type: knob
          param: semitones
          label: "Semitones"

Pour votre propre plugin, changez d'abord l'id, par exemple en com.votrenom.transposer : l'application refuse les id qui commencent par com.grooveforge. (voir Charger un fichier).

Champs de premier niveau

ChampRôle
idNom unique en forme de domaine inversé, comme com.votrenom.monfx. Les projets désignent le plugin par lui : ne le changez plus une fois votre fichier utilisé.
nameNom affiché dans le rack.
versionVotre numéro de version, en texte.
typemidi_fx (ou midifx), effect, instrument ou analyzer. Absent ou inconnu : effect.
parametersLes réglages modifiables. Voir Paramètres.
midi_nodesPour midi_fx : la chaîne de traitement. Voir Nœuds MIDI.
graphPour effect : le graphe audio. Voir Graphe audio.
uiLe panneau. Voir Panneau.

Les fichiers fournis commencent par spec: "1.0". L'application le lit mais ne le vérifie pas.

Paramètres

Une liste sous parameters:, une entrée par réglage.

ChampS'il manqueRôle
id(obligatoire)Clé texte. Les nœuds et les commandes s'y réfèrent, et les projets enregistrent la valeur sous cette clé.
paramId0Nombre, unique dans le fichier. Ne le réutilisez ni ne le renumérotez une fois le fichier en service.
nameVideLibellé sous la commande.
min, max0Plage affichée sur le panneau.
default0Valeur de départ, entre min et max.
unitVideTexte après la valeur, comme ms ou %.
typefloatfloat (continu), toggle (marche/arrêt) ou selector (un choix parmi options).
optionsAucunePour un selector : les libellés, dans l'ordre. Mettez min: 0 et max au nombre d'options moins un.
displayPas d'affichageAffiche la valeur sous la commande : integer (arrondie), value (arrondie, avec l'unité) ou interval (demi-tons et nom de l'intervalle).

Les nœuds ne voient pas min et max. Ils reçoivent la position de la commande, de 0 à 1, et appliquent leur propre plage : transpose fait toujours correspondre 0 à 1 à −24 à +24 demi-tons. Quand vous réutilisez un nœud, reprenez la plage du fichier fourni qui l'utilise, sinon le panneau affichera une valeur et le nœud en jouera une autre.

Nœuds MIDI

Une liste sous midi_nodes:. Les notes traversent les nœuds dans l'ordre de la liste. Chaque nœud a un id, un type et des params. Un paramètre de nœud est soit relié à un paramètre du plugin, { param: semitones }, soit fixe, { value: 0.5 }. Une valeur fixe s'exprime sur la même échelle de 0 à 1.

type de nœudParamètres du nœudExemple fourni
transposesemitonestransposer.gfpd
gateminVelocity, maxVelocity, minPitch, maxPitchgate.gfpd
harmonizevoiceCount, interval1 à interval4, snapToScaleharmonizer.gfpd
chord_expandchordType, spread, snapToScalechord_expand.gfpd
arpeggiatepattern, division, gate, octavesarpeggiator.gfpd
velocity_curvemode, amountvelocity_curve.gfpd
microtonechordWindow, clusterMode, bendRange, velocityModemicrotone.gfpd

Un seul type de nœud inconnu désactive toute la chaîne.

Graphe audio

Les effets fournis décrivent leur traitement sous graph:, avec nodes et connections. Comme dit plus haut, l'application n'exécute pas ce graphe aujourd'hui. Pour référence, la syntaxe : 

graph:
  nodes:
    - id: in
      type: audio_in
    - id: rev
      type: freeverb
      params:
        roomSize: { param: room_size }
    - id: mix_nd
      type: wet_dry
      params:
        mix: { param: mix }
    - id: out
      type: audio_out
  connections:
    - from: in.out
      to: [rev.in, mix_nd.dry]
    - from: rev.out
      to: mix_nd.wet
    - from: mix_nd.out
      to: out.in

audio_in et audio_out sont l'entrée et la sortie du plugin. Les autres types de nœud sont gain, wet_dry, freeverb, biquad_filter, delay, wah_filter, compressor et chorus. Une connexion part de nœud.port vers une cible ou une liste de cibles. Sans port, from vaut out et to vaut in.

Panneau

Sous ui:, soit une liste plate controls:, soit une liste de groups:. Si les deux sont là, les groupes l'emportent.

ChampRôle
layoutSans groupes : row (par défaut, une ligne qui défile) ou grid (passe à la ligne). Avec groupes : lanes empile chaque groupe sur sa propre ligne ; toute autre valeur place les groupes selon la taille de l'écran.
groupsChaque groupe a un label et sa propre liste controls.
activeWhenSur un groupe, avec layout: lanes uniquement : { param: voice_count, atLeast: 2 } grise le groupe tant que ce paramètre est en dessous de 2. La comparaison se fait dans les unités du paramètre.

Chaque commande a un type, et la plupart un param (l'id d'un paramètre). label remplace le nom du paramètre, et size vaut small, medium (par défaut) ou large.

type de commandeAffiche
knobUn bouton rotatif. Utilisé aussi pour un type absent ou inconnu.
sliderUn curseur.
toggleUn bouton marche/arrêt.
selectorUn choix parmi les options du paramètre.
intervalUne barre pour choisir un intervalle en demi-tons.
vumeterUn vumètre. Sans param.
buttonAvec action: reset, remet tous les paramètres à leur valeur par défaut. Sans param.
