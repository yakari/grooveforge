Plugins VST3

Utilisez les instruments et effets VST3 installés sur votre ordinateur comme modules du rack. Sur ordinateur uniquement : Linux, macOS et Windows.

Charger un plugin

Ajoutez au rack un instrument ou un effet installé.

  1. Touchez + et descendez jusqu'à Plugins VST3.
  2. Touchez Choisir un instrument installé ou Choisir un effet installé, puis choisissez un plugin dans la liste.
  3. Il n'y est pas ? Touchez Parcourir un instrument VST3… ou Parcourir un effet VST3… et sélectionnez le dossier .vst3 du plugin.

Le plugin apparaît dans le rack sous forme de module. Un instrument a un badge MIDI CH ; un effet n'en a pas.

La liste ne montre que les plugins placés directement dans ces dossiers. Pour un plugin rangé dans un sous-dossier, passez par Parcourir.

SystèmeDossiers parcourus
Linux~/.vst3, /usr/lib/vst3, /usr/local/lib/vst3
macOS~/Library/Audio/Plug-Ins/VST3, /Library/Audio/Plug-Ins/VST3
WindowsC:\Program Files\Common Files\VST3

Jouer d'un instrument VST3

Envoyez-lui des notes, comme à n'importe quel instrument.

  • Depuis un contrôleur MIDI : réglez le badge MIDI CH du module sur le canal de votre contrôleur.
  • Depuis le clavier à l'écran : dans la Vue de câblage, reliez le MIDI OUT du clavier au MIDI IN du plugin. Le guide montre la même chose avec Riff : Jouer de la guitare au clavier.

Les plugins suivent le tempo et la lecture de la barre de transport : les delays et arpégiateurs calés sur le tempo restent en place.

Mettre un effet après un instrument

Faites passer n'importe quel instrument, intégré ou VST3, dans un effet VST3.

  1. Chargez l'effet (voir plus haut).
  2. Dans la Vue de câblage, reliez les AUDIO OUT L et R de l'instrument aux AUDIO IN L et R de l'effet.

Vous entendez l'instrument à travers l'effet.

Sur un instrument VST3, il y a un raccourci : touchez FX en bas de son module, puis Ajouter un effet. Vous choisissez le dossier .vst3 de l'effet et les câbles sont tirés pour vous.

Régler le plugin

  • Dans le module, touchez PARAMETERS pour le déplier, puis un groupe pour ouvrir ses boutons. Un champ de recherche aide pour les plugins qui ont des centaines de réglages.
  • Sous Linux et macOS, touchez Show Plugin UI pour ouvrir la fenêtre du plugin.

Sous Linux, certains plugins dessinent leur fenêtre en OpenGL et ne s'ouvrent pas sous Wayland. L'application vous le signale. Lancez GrooveForge avec LIBGL_ALWAYS_SOFTWARE=1, ou dans une session X11, et réessayez.

Enregistrer le projet garde chaque plugin et les valeurs de ses paramètres.

Ce qui ne marche pas encore

  • Seules les notes arrivent à un instrument VST3. Le pitch bend, la molette de modulation et les autres messages de contrôle (CC) ne passent pas.
  • L'accordage microtonal de Xen ne s'applique pas aux instruments VST3 : ils jouent avec l'accordage habituel.
  • Sous Windows, la fenêtre du plugin ne s'ouvre pas.

Compiler GrooveForge vous-même

Le SDK VST3 de Steinberg n'est pas dans le dépôt. Avant de compiler pour Linux, macOS ou Windows, clonez-le dans packages/flutter_vst3/vst3sdk avec ses sous-modules. La commande est dans le README.
